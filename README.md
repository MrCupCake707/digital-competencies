# Digital Trajectory Pro

Desktop-приложение для формирования персональной траектории повышения цифровых компетенций сотрудника на основе графовой модели знаний.

## Что реализовано

- 17 компетенций и не менее 15 направлений цифрового развития.
- Графовая модель знаний: зависимости между компетенциями заданы как prerequisites.
- Алгоритм построения траектории с учетом текущего уровня, целевого уровня, веса компетенции и предварительных знаний.
- Desktop-интерфейс на tkinter.
- Локальное хранение профилей сотрудников в SQLite.
- Экспорт отчёта в Markdown, CSV и JSON.
- Читабельная архитектура: core, data, storage, ui, utils.
- Базовые тесты.
- Скрипт сборки .exe через PyInstaller.

## Запуск

```bash
python run.py
```

Если запускаете из папки выше проекта:

```bash
cd digital_trajectory_pro
python run.py
```

## Сборка .exe

Windows:

```bat
scripts\build_exe.bat
```

После сборки исполняемый файл появится в папке `dist`.

## Структура проекта

```text
app/
  core/       бизнес-логика: модели, граф, построитель траектории
  data/       JSON-данные компетенций и пример профиля
  storage/    загрузка данных и SQLite-хранилище
  ui/         desktop-интерфейс
  utils/      экспорт отчётов
docs/         пояснения и план коммитов
tests/        тесты
scripts/      сборка .exe
```

## Как защищать на ВКР

Приложение демонстрирует практическую часть работы: сотрудник оценивается по цифровым компетенциям, после чего модуль строит индивидуальную траекторию обучения. Графовая модель позволяет учитывать не только желаемое направление развития, но и предварительные знания, без которых освоение последующих компетенций будет затруднено.

## Что изменено в версии 1.1

- При запуске сначала открывается экран входа по ФИО.
- Если профиль найден, данные загружаются автоматически; если нет — создается новый профиль.
- Оценка компетенций выполняется числами от 0 до 5.
- Рядом с каждой компетенцией есть краткое пояснение и подсказка по уровню.
- Приоритет рекомендации ограничен максимумом 10 баллов.
- Добавлен экспорт отчета в Word `.docx`.
- Интерфейс оформлен в более современном стиле: карточки, акцентные кнопки, улучшенные таблицы.

## Что изменено в версии 1.4

- Реализован новый дизайн по брифу: спокойный corporate-интерфейс в тёплой светлой палитре.
- Добавлены menu bar, вкладки, статусная строка и главная страница с карточками статистики.
- Добавлен визуальный граф знаний: цветные вершины, направленные рёбра, сетка, перетаскивание узлов и подсветка траектории.
- Экран формирования траектории разделён на левую панель действий и правую область оценки компетенций.
- Оценка владения компетенциями выполняется строго по шкале 0–5.
- Траектория появляется после заполнения оценок и нажатия кнопки «Сформировать».
- Word-экспорт доступен после расчёта траектории.

## Примечание по коду
