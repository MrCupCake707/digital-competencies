# Release notes

## 1.1.0 — правки интерфейса и экспорта

- Добавлен стартовый экран: сначала пользователь вводит ФИО.
- Если профиль с указанным ФИО найден в SQLite, приложение открывает его автоматически.
- Если профиль не найден, создается новый профиль для регистрации сотрудника.
- Оценка компетенций переведена на шкалу 0-5.
- Рядом с каждой компетенцией добавлено краткое пояснение и текстовая подсказка уровня.
- Приоритет траектории нормирован по шкале 0-10.
- Добавлена выгрузка персональной траектории в Word-файл `.docx`.
- Обновлено визуальное оформление: карточки, акцентные кнопки, более аккуратные таблицы и подсказки.

## 1.0.0 — базовая версия

- Desktop-приложение на Python/Tkinter.
- Графовая модель цифровых компетенций.
- Не менее 15 направлений развития.
- SQLite-хранилище профилей.
- Экспорт в Markdown, CSV и JSON.

## v1.2 — доработка оценки и интерфейса

- Усилен визуальный стиль: добавлен стартовый hero-блок, статусная панель, визуальные карточки компетенций и более понятные кнопки действий.
- Результаты траектории больше не формируются автоматически после входа: сначала сотрудник вручную заполняет владение всеми компетенциями.
- Оценка владения компетенциями ограничена шкалой 1–5 через выпадающий список, значение 0 исключено из пользовательского ввода.
- Экспорт отчётов доступен только после формирования актуальной траектории.
- При изменении оценки результаты очищаются, чтобы пользователь не работал со старым расчётом.

## v1.3 — исправления интерфейса оценки

- Возвращена шкала владения компетенциями от 0 до 5.
- Новые профили больше не получают автоматически проставленные нули: пользователь должен заполнить каждую компетенцию вручную.
- Расширены и перенесены пояснения по баллам, чтобы текст был виден полностью.
- Левый дашборд получил вертикальную прокрутку, поэтому скрытый текст больше не обрезается.
- Исправлена логика отображения результата: после заполнения всех оценок и нажатия кнопки траектория снова выводится в таблицу.

## Версия 1.4 — redesign interface

- Интерфейс переработан по брифу «soft corporate».
- Добавлены верхнее меню, вкладки-закладки и строка статуса.
- Добавлена главная страница с карточками статистики.
- Разделы «Сотрудники», «Компетенции», «Граф знаний», «Траектория» и «Результаты» вынесены в отдельные вкладки.
- Реализован визуальный граф компетенций на Canvas: сетка, направленные связи, цветные вершины по категориям, перетаскивание узлов.
- После формирования траектории рекомендованные вершины и рёбра подсвечиваются.
- Экран оценки компетенций стал более читаемым: уровень 0–5, описание компетенции и пояснение по баллу отображаются в одной строке-карточке.
- Результаты автоматически открываются после расчёта траектории.
- Экспорт Word остаётся доступным только после формирования результата.

## v1.6 — Улучшение читаемости и пошаговая оценка

- Добавлена DPI-настройка для Windows, чтобы текст и линии не выглядели размытыми при масштабировании экрана.
- Переработан сценарий оценки компетенций: сначала показывается шкала 0–5, затем компетенции заполняются по очереди.
- Убрана перегруженная таблица оценивания, из-за которой текст выходил за рамки.
- Добавлены переносы текста и ограничения ширины для пояснений.
- Улучшена прокрутка таблиц и отображение длинных описаний.
- Бизнес-логика построения траектории, классы модели, сохранение и экспорт не изменялись.

## v1.7 — Увеличение читаемости и новая палитра

- Увеличены базовые размеры шрифтов интерфейса.
- Обновлена цветовая палитра по новому дизайн-брифу.
- Увеличены расстояния между вершинами графа знаний.
- Увеличены размеры графовых узлов и подписи внутри них.
- Обновлены цвета категорий, рёбер и подсвеченного пути.

## v2.0 — Форма входа и регистрация

- Первая страница заменена на форму входа по логину и паролю.
- Добавлена отдельная форма регистрации нового пользователя.
- Учётные записи сохраняются локально в SQLite.
- Пароли не хранятся открытым текстом: используется соль и PBKDF2-хеш.
- После входа или регистрации открывается основная часть приложения без изменения логики траектории.
