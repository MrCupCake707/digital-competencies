# Изменения версии 3.7

- Убраны устаревшие экраны входа и регистрации из интерфейса.
- Упрощен модуль базы данных: оставлены только используемые операции профилей и ролей.
- Справочник компетенций переведен в более понятный формат `knowledge_base.json`:

```json
{
  "DC01": {
    "Название": "...",
    "Описание": "...",
    "Сложность": 3,
    "Направление": "...",
    "Категория": "...",
    "Целевой уровень": 3,
    "Приоритет": 4,
    "Предварительные компетенции": [],
    "Материалы": []
  }
}
```

- Добавлены поля «Сложность» и «Категория» для компетенций.
- Администратор может заполнять сложность и категорию при добавлении новой компетенции.
- Сохранение компетенций вынесено в отдельную функцию `save_competences()`.
- Код основных модулей стал короче и чище.
