# Формат файла competences.json

Файл `app/data/competences.json` хранит справочник цифровых компетенций в человекочитаемом виде.

Основной раздел — `Компетенции`. Внутри него каждая компетенция имеет код, например `DC01`.

Пример одной компетенции:

```json
"DC01": {
  "Название": "Цифровая грамотность",
  "Краткое описание": "Уверенная работа с ОС, файлами и офисными инструментами.",
  "Сложность": 3,
  "Направление": {
    "Номер": 1,
    "Название": "Базовая цифровая грамотность"
  },
  "Категория": "Базовые навыки",
  "Целевой уровень": 3,
  "Приоритет": 4,
  "Зависит от": [],
  "Материалы": []
}
```

Шкалы:

- `Сложность`: от 1 до 5.
- `Целевой уровень`: от 0 до 5.
- `Приоритет`: от 1 до 10.

Категория используется для цвета узла на графе компетенций.
