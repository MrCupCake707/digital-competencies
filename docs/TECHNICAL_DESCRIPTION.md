# Техническое описание

## Назначение

Программа предназначена для автоматизированного формирования персональной траектории повышения цифровых компетенций сотрудника.

## Модель данных

Каждая компетенция хранится как вершина графа. Связи `prerequisites` задают предварительные знания. Это позволяет учитывать порядок освоения материала.

## Алгоритм

1. Пользователь выбирает направление развития.
2. Программа выбирает компетенции выбранного направления.
3. К ним добавляются все предварительные компетенции.
4. Граф сортируется топологически.
5. Для каждой компетенции рассчитывается разрыв между текущим и целевым уровнем.
6. Разрыв умножается на вес компетенции.
7. Если есть пробелы в предварительных знаниях, приоритет дополнительно увеличивается.
8. На выходе формируется список шагов обучения.

## Формула приоритета

`priority = gap * weight + prerequisite_gap * 0.5`

где `gap` — разрыв между текущим и целевым уровнем, `weight` — значимость компетенции, `prerequisite_gap` — суммарный разрыв по предварительным компетенциям.
